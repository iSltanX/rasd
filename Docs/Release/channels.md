# قنوات النشر — ما نُشر وأين

> **رقمٌ واحد يعلو دائمًا، وقنوات تنشر منه ما تحتاج** (`Docs/Browsers/Architecture.md` §4.8). يُحدَّث هذا الجدول بالتزامٍ
> مع كل تقديم إلى متجر، وتقرؤه `browsers.json` لا العكس. الحزمة التي تُرفع هي ما في مسوَّدة الإصدار على GitHub بعد مطابقة
> بصمتها: `shasum -a 256 -c rasd-<النسخة>.zip.sha256`.

**Chrome Web Store منشورة بالإصدار 1.0.0، وFirefox Add-ons بالإصدار 1.0.1** (2026-10-09)، وصفحتاهما تعيدان 200 لزائرٍ غير مسجَّل
(Firefox قِيست 2026-10-06 و2026-10-09، وحالتها `public` في واجهة AMO البرمجية). وEdge وOpera لم تُنشرا بعد. النشر لكل متجر بيد المالك وحده
(`AGENTS.md` §7)، ويُملأ السطر بعد النشر لا قبله.
