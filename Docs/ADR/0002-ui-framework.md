# ADR 0002 — إطار الواجهة: Preact

**الحالة:** معتمد · **المرحلة:** 1 · **التاريخ:** 2026-08-28

## السياق

`Rasd_Ar.md §20.5` يجعل «خفة الإضافة وقلة تأثيرها على الصفحة» ميزة جوهرية، والمرحلة 24
تحوّلها إلى ميزانية مفروضة في CI: **حزمة content script ≤ 120KB مضغوطة**.

الواجهة تُحقن داخل صفحات لا نملكها، فكل كيلوبايت يُحمّل على صفحة المستخدم لا على صفحتنا.

## القرار

**Preact 10 + `@preact/signals`** لكل الواجهات: صفحات الإضافة والطبقة داخل الصفحة معًا.

- Preact ≈ 4KB مضغوطة مقابل ≈ 45KB لـReact + ReactDOM. الفرق وحده يستهلك ثلث ميزانية الـcontent script.
- `@preact/signals` يعطي تفاعلية دقيقة الحبيبات بلا إعادة رسم شجرة — يناسب طبقة تُعاد رسمتها مع كل حركة مؤشِّر.
- JSX يُترجَم بـesbuild مباشرة (`jsx: 'automatic'`, `jsxImportSource: 'preact'`) بلا Babel.

## النتائج

- إطار واحد للسياقين — لا ازدواج في المكوّنات بين الصفحات والطبقة.
- `@preact/preset-vite` (ومعه Babel) **لم يُضَف**: لا مكوّنات بعد، وإضافة Babel لصفر مكوّنات سابقة لأوانها.
  إن احتاجت المرحلة 5 إلى prefresh HMR، يُضاف حينها ويُحدَّث هذا القرار.
- مكتبات React الجاهزة غير متاحة مباشرة؛ مقبول لأن نظام التصميم مبنيّ من الصفر على توكنز Figma.
