# SS10 — نشر رصد 1.0

> ورثت ما كان في المرحلة 30 القديمة (`STAGES/30.md`، نُقلت). النشر لا يُعكَس؛ كل ما قبله شرط، **والتقديم بأمر المالك وحده
> ومن حسابه** (`AGENTS.md` §0 و§7).

## الهدف

رصد 1.0 منشور في Chrome Web Store وMicrosoft Edge Add-ons وFirefox Add-ons وOpera Add-ons (قرار المالك 2026-10-02: ضمن 1.0) من الحزم الثلاث نفسها
لوسمٍ واحد `v1.0.0`، وسجلّ القنوات يقول ما نُشر أين، ومسار 1.1 مفتوح.

## النطاق

**الملفّات المتوقَّع تأثّرها**

- `package.json` ⇐ `1.0.0`، و`CHANGELOG.md` ⇐ عنوان `1.0.0` ببنوده
- `src/shared/links.ts` ⇐ `OWNER_PAGES_LIVE = true` بعد أن تعيد الصفحات الثلاث 200 (`Docs/Store/owner-pages.md`)
- وسم `v1.0.0` ⇐ `release.yml` يرفق الحزم الثلاث
- `Docs/Release/channels.md` ⇐ صفّ لكل قناة بنسختها وتاريخها وبصمتها
- `ROADMAP.md` و`Docs/SS/README.md` ⇐ قائمة 1.1 من `Docs/Engineering.md §4`

**توسيع النطاق بأمر المالك (2026-10-02)** — التقديم العامّ النهائي ضمن SS10 لا بعدها، من إطارات Figma المعتمدة
(الملفّ `Gr0dOsmjcVBcaX9M1slf5m`: الصفحات 28 و29 و33 و34 و35):

- `README.md` ⇐ README النهائي بالعربية والإنجليزية من الصفحة 35 (الصور الأربع عشرة في `Docs/Launch/readme/`)
- مستودع الموقع `iSltanX/WebSiteSultan` ⇐ `/rasd` بالعربية و`/rasd/en` بالإنجليزية، و`/rasd/privacy` و`/rasd/support`
  و`/rasd/legal` و`/rasd/uninstall` (ونظائرها تحت `/rasd/en/`)، بالنصوص الحرفية من `Docs/Store/`
- قرارات المالك في الجلسة: جواب صفحة ما بعد الإزالة يُرسَل بريدًا عبر Resend القائم في الموقع إلى `isultanby@gmail.com`
  (السبب وحده) · الإنجليزية تحت `/rasd/en/*` · الدمج في `main` الموقع (= الإنتاج) بعد خضرة فحوصه المطلوبة

**خارج النطاق**

- أيّ شيفرة في الإضافة سوى الثابت ورقم النسخة
- جعل المستودع عامًّا (قرار المالك المستقلّ)

## المهامّ

1. تحقّق صفحات المالك الثلاث (`curl -sI`) ثمّ قلب `OWNER_PAGES_LIVE` بالتزام، واختباراته.
2. `1.0.0` في `package.json` و`CHANGELOG.md`، ثمّ `pnpm build:all && pnpm zip:all` والبصمات، ثمّ الوسم `v1.0.0` ومسوَّدة الإصدار.
3. التقديم بأمر المالك: Chrome وEdge (مواد `Docs/Store/`)، وAMO (الحزمة + المصدر، والتوقيع)، وOpera (مواد `Docs/Store/opera/` ونصّ `Docs/Store/eula.md` جاهزان). نشر متدرّج حيث يتاح.
4. `channels.md` بصفوفه، ومراقبة أوّل بلاغات بعد النشر (`label:product:rasd`).
5. فتح قائمة 1.1.

## معايير الإغلاق

- `git tag -l v1.0.0` يعيد الوسم وهو على `origin`، ومسوَّدة الإصدار تحمل الحزم الثلاث ببصماتها
- `pnpm vitest run tests/unit/pages/settings/about-section.test.tsx tests/unit/background/uninstall-url.test.ts tests/unit/changelog.test.ts` أخضر بعد قلب الثابت ورفع النسخة
- `Docs/Release/channels.md`: صفّ لكل قناة قُدِّمت بنسختها وتاريخها وبصمتها، والحالة «منشورة» عند 100%
- النشر عند 100% في كل قناة قُرّرت

## المخاطر

- النشر لا يُعكَس: لا تقديم قبل أمر المالك الصريح لكل متجر على حدة
- مراجعة AMO قد تُختار يدوية وتطول؛ وOpera أبطأ: التواريخ تُكتب في `channels.md` كما وقعت
