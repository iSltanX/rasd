# مواد الإطلاق — رصد

> كل ما يُرى من رصد خارج الإضافة: لقطات المتجرين، والترويجيتان، والأيقونة، وصور README، وشريط المتصفّحات. **لا صورة
> هنا مرسومةٌ بيد ولا واجهةٌ مصطنعة:** كل لقطة شاشةٌ حيّة من الإضافة المبنيّة كما يرسمها Chrome (`pnpm design:shots --dpr=2`)،
> والإطار حولها وحده يُولَّد، بالهوية نفسها — الشعار والحبر والإشارة وخطّا Almarai وCairo ([`Docs/Brand/`](../Brand/README.md)).
>
> نصوص المتجر نفسها (الوصف والغرض والخصوصية) في [`Docs/Store/listing.md`](../Store/listing.md)، ونتيجة اختبار المتصفّحات
> في [`browsers.md`](browsers.md).

## إعادة التوليد

```text
pnpm build:bundle               # الحزمة المبنيّة
pnpm design:shots --dpr=2 --only=overlay,editor,library,settings   # لقطات حيّة بكثافة 2× → artifacts/design/shots@2x/
pnpm launch:images              # الإطارات كلّها → Docs/Launch/ (--only=screens,opera,promo,readme لما يقرأ اللقطات وحده)
pnpm vitest run tests/unit/store-materials.test.ts   # المقاسات والمصادر وصدق «مدعوم»
```

| المصدر                            | ما يحكم                                                                                      |
| --------------------------------- | -------------------------------------------------------------------------------------------- |
| [`content.json`](content.json)    | ترتيب اللقطات ونصوصها بالعربية والإنجليزية، ونصّ البطل والترويجيتين وشريط المتصفّحات         |
| [`browsers.json`](browsers.json)  | المتصفّحات المجرَّبة ونتيجتها — لا يظهر في شريط «يعمل حيث تعمل أنت» إلا ما حالته `supported` |
| `scripts/launch-images.mjs`       | التكوين (HTML يرسمه Chrome)، بإطلاقٍ واحد لكل الصور                                          |
| `artifacts/design/shots@2x/*.png` | اللقطات الحيّة بكثافة 2× — تُولَّد ولا تُحفظ في Git                                          |
| `scripts/site-images.mjs`         | قصّات صفحة رصد في الموقع (`bysltan.com/rasd`) من اللقطات نفسها، بمربّعات Figma (الصفحة 28) — إلى `public/rasd/shots/` في مستودع الموقع |

## اللقطات — `screens/` · 1280×800

فكرةٌ واحدة لكل لقطة، من ميزةٍ منفَّذة لها حارس أو اختبار ([`Docs/Store/features.md`](../Store/features.md)). كلٌّ
بنسختين: `ar-` بعنوانٍ عربي و`en-` بعنوانٍ إنجليزي فوق الواجهة العربية نفسها.

| الملفّ          | الفكرة                             | Chrome Web Store | Edge Add-ons | README |
| --------------- | ---------------------------------- | ---------------- | ------------ | ------ |
| `01-inspect`    | فحص أي عنصر وتنزيل أنماطه          | ✓ (1)            | ✓ (1)        | ✓      |
| `02-measure`    | القياس بين عنصرين بالبكسل          | ✓ (2)            | ✓ (2)        | ✓      |
| `03-compare`    | المقارنة بالمرجع فوق الصفحة الحيّة | ✓ (3)            | ✓ (3)        | ✓      |
| `04-editor`     | الملاحظات والحجب المخبوز في الصورة | ✓ (4)            | ✓ (4)        | ✓      |
| `05-library`    | المكتبة على الجهاز                 | ✓ (5)            | ✓ (5)        | ✓      |
| `06-local-only` | «الوضع المحلّي فقط» افتراضيًّا     | —                | ✓ (6)        | ✓      |
| `07-colours`    | قراءة اللون كما يُرسم              | —                | —            | ✓      |
| `08-capture`    | التقاط منطقةٍ بأبعادها             | —                | —            | ✓      |

**الرفع:** Chrome يقبل خمس لقطات على الأكثر، وEdge ستًّا (`Docs/Store/checklist.md` البندان 21 و37). اللقطات
لكل لغة في المتجر: العربية `ar-*` في قائمة العربية، والإنجليزية `en-*` في قائمة الإنجليزية.

## لقطات Opera — `screens/opera-*` · 612×408

إرشادات نشر Opera: المقاس المفضَّل 612×408 (الأقصى 800×600) و**خلفية بيضاء**، فهي اللقطات الحيّة نفسها (الخمس الأولى من الجدول)
مصغَّرةً بنسبتها على أبيض بعنوانها فوقها: `opera-ar-01-inspect.png` … `opera-en-05-library.png`. وتقترح الإرشادات لقطتين
(كيف تعمل وكيف تبدو)، فتُرفع `01-inspect` و`02-measure`. تُولَّد بـ`pnpm launch:images --only=opera`.

## ما لا يظهر في أي صورة

بيانات العيّنات خيالية (مجلة الطيف، Northwind، وأسماء مواقع مختلقة). ولقطة المحرّر المختارة هي لقطة **الحجب**: صفحة
العيّنة تحمل بريدًا وهاتفًا ورقم حساب مختلقة لاختبار الحجب، ولا تظهر إلا محجوبةً. ولقطات `export_modal` و`editor_annotating`
مستبعدة لأنها تُظهر تلك القيم مكشوفة. ولا مسار جهاز ولا أداة تنقيح في أي إطار.
