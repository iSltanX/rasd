# قائمة Firefox اليدوية

> ما لا يُؤتمت في Firefox ويُجرَّب بيد على `dist-firefox/`. كل بند بحالته ودليله وتاريخه. تبدأها SS6 ببندَي الأذونات،
> وتُكمل SS8 بقيّة البنود (الأيقونة والاختصار والنافذة الخاصّة وويندوز).
