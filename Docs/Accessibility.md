## جولة لوحة المفاتيح

الاتّجاه RTL: **Tab يمضي من اليمين إلى اليسار ومن الأعلى إلى الأسفل**، وShift+Tab عكسه. ما يلي ترتيب المحطّات كما
قرأه المتصفّح فعلًا (`keys-trails.json`)، لا ما يُفترض.

### الصفحات

| الصفحة        | الترتيب                                                                                                                                                                                                                                                                                                 |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **النافذة**   | الإعدادات ← أدوات الالتقاط الأربع (منطقة `T` · عنصر `E` · الظاهر `V` · صفحة كاملة `S`) ← فحص ← قياس ← ألوان ← مقارنة ← «عرض الكل» ← آخر اللقطات ← المكتبة ← الإعدادات                                                                                                                                   |
| **المحرّر**   | عودة إلى المكتبة ← نسخ الصورة ← تصدير ← مشاركة ← الأدوات (تحريك · سهم · مستطيل · دائرة · تحديد حرّ · ملاحظة · دبّوس · حجب وطمس · قياس · خطّ · نصّ · اقتصاص) ← الألوان السبعة ← لوحة الملاحظات (عنوان ← متن ← أزرار الأنماط)                                                                             |
| **المكتبة**   | شعار المكتبة ← لقطة جديدة ← المنطقة الجانبية (كل اللقطات · المميّزة · الأخيرة · المشاريع · اللوحات · الألوان · المراجع · أدلة الخطوات · المشكلات · الإعدادات) ← البحث ← نوع اللقطة ← التاريخ ← لوحتا الوسوم والمشاريع ← اللقطات/نشِطة ← الترتيب ← بطاقات اللقطات (خانة التحديد ثمّ زرّ الفتح لكل بطاقة) |
| **الإعدادات** | المنطقة الجانبية نفسها ← أقسام الإعدادات التسعة (التصوير · التعليقات · الألوان · المظهر · الاختصارات · الخصوصية · البيانات · التكاملات · عن رصد) ← عناصر القسم المفتوح                                                                                                                                  |
| **التعريف**   | تخطَّ ← التالي (والخطوة الأخيرة: ابدأ)                                                                                                                                                                                                                                                                  |
| **المقارنة**  | تصدير التقرير ← التقط الفرق ← موضع الفاصل ← أنماط العرض ← مناطق الفرق (السابقة ← الأرقام ← التالية) ← ارسم مستطيلًا ← حساسية المقارنة                                                                                                                                                                   |

### الحوارات

حوارٌ مشروط (`aria-modal`) **يحبس Tab**: من آخر عنصر إلى أوّله ومن أوّله إلى آخره، ويعيد التركيز عند الإغلاق إلى
الزرّ الذي فتحه. أربعة عشر حوارًا، كلٌّ بترتيبه بعد الإصلاح:

| الحوار         | المحطّات                                                                             |
| -------------- | ------------------------------------------------------------------------------------ |
| مغادرة بلا حفظ | غادر بلا حفظ ← احفظ وغادر ← أغلق ← ابقَ                                              |
| التصدير        | الاسم ← الدقّة ← انسخ إلى الحافظة ← تنزيل ← إغلاق                                    |
| التصدير — تمّ  | انسخ إلى الحافظة ← افتح المجلّد ← إغلاق                                              |
| الحذف النهائي  | احذف ← أغلق ← ألغِ (التركيز يبدأ على «ألغِ»)                                         |
| ما الجديد      | أغلق ← تمّ                                                                           |
| الاختصارات     | غيّر اختصارات الالتقاط ← أغلق                                                        |
| نوافذ القفل    | الرمز ← أعد كتابة الرمز ← ألغِ ← أغلق ← أنشئ نسخة (وفكّ المكتبة: نسيت الرمز ← الرمز) |

و`Esc` يغلق كل حوارٍ يُغلَق، ويُلغي ما يقبل الإلغاء أثناء عملٍ جارٍ (التصدير والنسخ).

### الطبقة فوق الصفحة

الأدوات تُفعَّل من النافذة أو اختصارها، ومفاتيحها من المصدر لا من الذاكرة:

| الأداة      | المفاتيح                                                    |
| ----------- | ----------------------------------------------------------- |
| تحديد منطقة | `⇧` تثبيت النسبة · `⌥` من المركز · `↵` التقاط · `Esc` إلغاء |
| اختيار عنصر | `↑` `↓` تنقّل في شجرة DOM · `Esc` خروج                      |
| لوحة الفحص  | تبويباتها `←` `→` `Home` `End` (والاتجاه RTL يعكس الأسهم)   |
| مقارنة      | مقبض الفاصل بالأسهم                                         |

و`Esc` يخرج من كل أداة بإشعار «خرجت من …». **ولا جولة Tab آلية داخل لوحات الطبقة**: الأدوات تُدار بمؤشّر
وبمفاتيح الجدول أعلاه، لا بالمرور على أزرار. فوق ذلك أوضاعها الخمسة مفحوصة بـaxe في الحارس، وكل مشاهدها (63) في
`design:shots --axe`، ومفاتيحها مفحوصة في `verify:picker` و`verify:compare` و`verify:palette`.

## ما وجدته الجولة وأُصلح

**12 حوارًا مشروطًا لم يحبس Tab** (والحوارات المشروطة 14؛ حوار الحذف وحوار البيانات وحدهما يحبسانه، كلٌّ بنسخته):
نوافذ التصدير وتقدّم التصدير وإتمامه ومغادرة المحرّر ومشاركة اللقطة وتصدير دليل الخطوات وتسليم المطوّر وتقرير
المقارنة وحفظ الفرق وما الجديد والاختصارات والتراخيص. `aria-modal="true"` يعد قارئ الشاشة بأن ما وراء الحوار غير قائم، وكان Tab يخرج منه
إلى أزرار المحرّر أو المكتبة خلفه — فيصير التركيز على ما لا يُرى. **لم يلتقطه axe** (لا قاعدة له) ولا Lighthouse؛
التقطته الجولة الحيّة: في نافذة التصدير 39 محطّة بينها «عودة إلى المكتبة» و«تصدير» وراءها. أُصلح بخطّاف مشترك
`src/ui/use-focus-trap.ts` تستعمله الحوارات كلّها (وانتقل إليه حوارا الحذف والبيانات فلا نسختان)، ويقفل
اختبارٌ الباب: ملفّ فيه `aria-modal` بلا الخطّاف يُسقطه.

## ما لم يُغلق

- **مراجعة بقارئ شاشة بشريّة** (VoiceOver مع Chrome، ثمّ NVDA إن أمكن). المهمّة الثالثة في المرحلة تشترط أذنًا
  بشريّة: هل الاسم المنطوق مفهوم؟ هل ترتيب القراءة منطقيّ؟ هل تُعلَن حالات التحميل والخطأ؟ ما أُنجز آليًّا: **كل
  عنصر تفاعلي بلا اسم صفر** في أشجار الإتاحة المحفوظة (`tests/visual-baselines/**/*a11y-tree.md`)، وشجرة Chrome لا
  تغني عن السماع. لا يُعلَن إغلاق هذه المهمّة إلا بتسجيل نتيجة مراجعةٍ فعليّة هنا.
- **`tertiary` على `pressed` في الفاتح: 4.49:1** — دون حدّ AA بفارقٍ ضئيل، في حالة انتقالية (لحظة الضغط على
  بطاقة أداة). التوكنز مولَّدة من لقطة Figma فلا تعديل يدوي عليها (ADR 0007): قرار تصميم. مثبَّت باسمه في
  `tests/unit/token-text-contrast.test.ts` ويُسقطه حين يبلغ الزوج 4.5 فيُحذف الاستثناء.
- **Lighthouse بالوضع الفاتح وحده:** لا يحاكي تفضيل اللون. والداكن في بنود axe (التباين مفحوص بالوضعين).
- **Lighthouse على الحالة الافتراضية لكل صفحة**، لا على كل حالة: يحمّل الصفحة بنفسه فلا يحمل حالةً مزروعة. وأحوال
  الصفحات كلّها في بند axe المشهدي.
- **تقليل الحركة: مؤشّر التحميل (`Spinner`) يبقى يدور بسرعةٍ أبطأ** (1.2s) لا يتوقّف — إيقافه يُخفي أن شيئًا يجري. هو
  الاستثناء المسمّى الوحيد في الاختبار الساكن وفي الحارس.
