# حزمة التسليم — المخطّط المنشور `rasd.handoff/1`

> **ما هذا الملفّ:** عقد JSON حزمة التسليم لمن يكتب أداةً تقرؤها. المخطّط الآلي في
> [`Schemas/rasd.handoff-1.schema.json`](Schemas/rasd.handoff-1.schema.json) (JSON Schema 2020-12)، والقارئ
> التنفيذي في `src/modules/handoff/schema.ts`، والقرار في [ADR 0036](ADR/0036-handoff-model.md) والحاوية في
> [ADR 0037](ADR/0037-package-writer.md). ويحرس اتّساق الثلاثة `tests/unit/modules/handoff/json.test.ts`:
> حقلٌ في المخطّط غائبٌ عن هذا الملفّ يُسقطه.

## الحزمة

ملفّ ZIP واحد (`rasd-handoff-YYYY-MM-DD.zip`) يُفكّ بأي أداة قياسية، بأسماء ثابتة:

| المسار                | المحتوى                                                   |
| --------------------- | --------------------------------------------------------- |
| `rasd-handoff.md`     | Markdown يقرؤه إنسان ويُلصق في مساعد برمجة كما هو         |
| `rasd-handoff.json`   | هذا المخطّط                                               |
| `images/issue-NN.png` | مقتطع لقطة الدليل حول العنصر، بعد الحجب، بلا بيانات وصفية |

كل صورة يذكرها `rasd-handoff.md` أو `rasd-handoff.json` موجودةٌ في الحزمة بالاسم نفسه، والكاتب يرفض حزمةً فيها
مرجعٌ بلا ملفّ. والمشكلتان اللتان تشتركان في لقطة دليل واحدة تشيران إلى الصورة نفسها.

## قواعد العقد

- **الوسم أوّلًا:** `schema` يساوي `rasd.handoff/1`. قارئٌ يرى رقمًا أكبر ممّا يعرف يرفض الملفّ ولا يقرؤه
  ناقصًا.
- **التطوّر:** أي تغيير يرفع الرقم، ولا يُحذف حقلٌ في نسخة واحدة. والكائنات مغلقة: لا حقول غير المذكورة هنا.
- **الغائب `null`** لا حقلٌ محذوف.
- **الأزمنة** ISO 8601 بـUTC وبالمللي ثانية: `2026-09-30T12:00:00.000Z`.
- **الأطوال** بالبكسل المنطقي (CSS) إلا `evidence.crop` فببكسل الصورة.
- **الرابط** بلا استعلام ولا جزء ما لم يُطلب إبقاؤه — وحينها `options.keepQuery` صادقة.

## المشكلة — `issues[]`

| الحقل        | النوع                                      | المعنى                                                                                                                                                              |
| ------------ | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`         | نصّ                                        | معرّف المشكلة في رصد — ثابتٌ عبر الحزم، فيصلح مفتاحًا لإزالة التكرار                                                                                                |
| `ordinal`    | عدد صحيح ≥ 1                               | رتبتها في هذه الحزمة، وهو رقمها في عنوان Markdown                                                                                                                   |
| `title`      | نصّ                                        | عنوان المشكلة كما كتبه المستخدم                                                                                                                                     |
| `body`       | نصّ                                        | الملاحظة، وقد تكون فارغة                                                                                                                                            |
| `status`     | `open` · `needs-verification` · `resolved` | الحالة كما هي في رصد لحظة البناء                                                                                                                                    |
| `createdAt`  | زمن                                        | متى سُجّلت                                                                                                                                                          |
| `lastCheck`  | كائن أو `null`                             | `{ at, outcome, observed, reason }` — آخر إعادة فحص: `outcome` من `match` · `mismatch` · `not-found` · `changed` · `unreliable`، و`reason` لماذا لم يُحكم أو `null` |
| `page`       | كائن                                       | `{ url, title, viewport: { width, height, dpr } }` — الصفحة وعنوان تبويبها ومقاس النافذة وقت التسجيل                                                                |
| `element`    | عنصر                                       | العنصر المفحوص — الجدول التالي                                                                                                                                      |

| `properties` | كائن أو `null`                             | الخصائص بثلاث صيغ — `null` حين أُسقطت أو لا خاصية CSS في المشكلة (المسافة)                                                                                          |
| `evidence`   | كائن أو `null`                             | `{ image, crop }` — مسار الصورة في الحزمة وموضع العنصر فيها؛ `null` حين أُسقطت الصور                                                                                |

### العنصر — `element` و`pair`

| الحقل        | المعنى                                                                        |
| ------------ | ----------------------------------------------------------------------------- |
| `selector`   | المحدِّد كما ولّده رصد، نسبةً إلى جذر العنصر (المستند أو جذر الظلّ)           |
| `unique`     | هل طابق عنصرًا واحدًا وقت التسجيل                                             |
| `positional` | هل يعتمد على الترتيب (`:nth-child`) — هشٌّ عند تغيّر بنية الصفحة              |
| `inShadow`   | هل العنصر داخل Shadow DOM                                                     |
| `hosts`      | محدِّدات مضيفي الظلّ من المستند إلى جذر العنصر — فارغة خارج الظلّ             |
| `rect`       | `{ x, y, width, height }` في إحداثيات المستند وقت التسجيل — للعرض لا للمطابقة |

### الفحص — `check`

| `kind`     | `property`                                                        | `actual` و`expected` و`current`                | `tolerance`     |
| ---------- | ----------------------------------------------------------------- | ---------------------------------------------- | --------------- |
| `style`    | خاصية CSS: `padding` · `font-size` · …                            | قيم CSS كما يعيدها المتصفّح أو يكتبها المستخدم | بكسل            |
| `spacing`  | `gap-top` · `gap-right` · `gap-bottom` · `gap-left` · `dx` · `dy` | طولٌ بين العنصرين                              | بكسل            |
| `colour`   | خاصية لون CSS                                                     | ألوان                                          | فرق OKLab × 100 |
| `contrast` | `color/background-color`                                          | نسبة (`3.68`)، و`expected` حدٌّ أدنى           | بلا معنى — `0`  |

`actual` القيمة وقت التسجيل، و`current` القيمة الآن: آخر ما رصدته إعادة الفحص، وإلا `actual` — و`null` حين
لم يُعثر على العنصر في آخر فحص.

### الخصائص — `properties`

| الحقل      | المعنى                                                                                                                                   |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `css`      | كتلة CSS جاهزة للّصق — المخرج نفسه الذي تنسخه لوحة الفحص                                                                                 |
| `tailwind` | أصناف Tailwind v4 مع ما تعذّرت مقابلته تعليقًا                                                                                           |
| `rootPx`   | خطّ الجذر الذي حُوّلت عليه `rem` — **مفترَضٌ 16**: لم يُحفظ مع المشكلة                                                                   |
| `palette`  | للمشكلة اللونية: اللون المتوقَّع متغيّر CSS (`--expected-1`)، وإلا `null`                                                                |
| `inspect`  | كائن `rasd.inspect/1` كما تنسخه لوحة الفحص JSON — عقده يملكه `style-export`، وموضعه `rect.x`/`y` موضع المستند لأن إزاحة النافذة لم تُحفظ |

والقيم كلّها من لقطة الفحص المحفوظة مع المشكلة وقت التسجيل — لا من الصفحة الآن.

## Markdown

يقرأ النموذج نفسه، فكل ما فيه في JSON. بترتيبٍ ثابت لكل مشكلة: العنوان مرقَّمًا، ثمّ الحالة وآخر فحص،
والصفحة، والمقاس ووقت التسجيل، والمحدِّد بهشاشته، والفحص، والقيمة الآن، ووقت التسجيل إن اختلفت، والمتوقَّعة،
ثمّ الملاحظة اقتباسًا، وخطوات الإعادة، والخصائص (CSS وTailwind؛ وJSON الخصائص في `rasd-handoff.json`)، ثمّ
الصورة. القيم التقنية مقاطع برمجية معزولة الاتجاه (`U+2066`…`U+2069` خارج علامتَي المقطع)، والنصّ الحرّ
مهرَّب فلا يصير رابطًا ولا وسمًا ولا عنوانًا.
