# شجرة الإتاحة — جولة التعريف ‹ الخطوة ١

مولَّدة بـ`pnpm design:shots --baselines` من `Accessibility.getFullAXTree` في Chrome حقيقي،
بالوضع الداكن وRTL. **تُقرأ بالعين ولا تُقارَن آليًّا**: التغيّر فيها متوقَّع مع كل إضافة،
والمقصود أن يمرّ عليها قارئ حين يتغيّر شيء — لا أن تُسقط البناء.

العناصر التفاعلية والبنيوية: 5 · **بلا اسم: 0** (من 27 عقدة فعّالة)

```

region — افحص أي صفحة من مكانها
heading — افحص أي صفحة من مكانها
button — تخطَّ

```
