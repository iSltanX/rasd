# `shared/` — الطبقة القاعدية

الأنواع، عقد الرسائل، معالجة الاتجاه ثنائي اللغة (bidi)، الإعدادات، و`Result`.

**لا كتالوج توطين هنا**: القرار النهائي في [ADR 0022](../../Docs/ADR/0022-i18n-catalog-dropped.md)
— رصد عربيّ فقط، ولا يُبنى كتالوج رسائل ثانٍ. كان هذا السطر يَعِد بـ«التوطين» منذ
المرحلة 3 بلا ملفّ خلفه (ADR 0014 ملحق i18n)؛ صُحِّح بإغلاق الوعد لا بحذفه صامتًا.

**الحدود:** لا يستورد من أي طبقة أعلى منه — لا `background/` ولا `content/` ولا
`offscreen/` ولا `pages/` ولا `modules/` ولا `ui/` ولا `tokens/`. تُفرض القاعدة آليًا.
